# AI Resume Analyzer & Job Match Automation

## Overview

This project automates candidate screening using N8N and Google Gemini AI.

## Features

* Google Forms Integration
* Google Sheets Trigger
* AI Candidate Analysis
* Automated Email Reports
* End-to-End Workflow Automation

## Tech Stack

* N8N
* Google Sheets
* Gmail
* Google Gemini AI

## Workflow

Google Form → Google Sheets → AI Agent → Gmail

## Problem Solved

This workflow reduces manual recruiter effort by automatically collecting candidate information, analyzing profiles using AI, and generating personalized assessment reports through email. It helps streamline the hiring process and improve hiring efficiency.
